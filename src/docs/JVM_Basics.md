# JVM
It runs the Java program by executing the bytecode(.class) and this makes the code platform independent.

# JRE
It provides everything needed to run a Java program like JVM + core java libraries.

# JDK
Its is full package to develop and run Java programs. It includes JRE + development tools.

# Bytecode
When a java program gets compiled(javac) it creates .class file which is bytecode which is a platform independent code that can be executed on any machine with JVM.

# "write once, run anywhere” meaning
This means that you can write your Java code once and it can run on any platform that has a compatible JVM without needing to modify the code. This is because Java code is compiled into bytecode, which is interpreted by the JVM, allowing for cross-platform compatibility..
