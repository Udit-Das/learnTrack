# Setup Instructions

## JDK version used
- JDK 17

## “Hello World” program
The Main.java file contains a simple "Hello World" program. When executed, it prints the message Hello and welcome! to the console.
### To run the program:  
- Build the project using Maven:
  mvn clean install

- Execute the program:
  Go to Main class and right click and Run.

- Expected Output:
Hello World!
